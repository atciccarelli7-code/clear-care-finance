# Phase 2 Public Site Reorganization — Release Notes

## Summary

Reframes Community Acquired Finance around useful free education and tools plus one visible paid flagship: the Healthcare Worker Benefits Decision System.

## Public changes

- Homepage now explains the decisions CAF helps with and the free-preparation versus paid-completion model.
- Start Here adds a clear, optional handoff for healthcare workers with multi-part open-enrollment decisions.
- Tools explicitly identifies every listed public tool as free.
- Healthcare Workers now contains the flagship preview and explains the planned Open Enrollment Workspace.
- The former Benefits Command Center is presented as a free workplace-benefits comparison rather than a competing product identity.
- Header and footer distinguish free resources, audiences, and the Decision System.
- Metadata and product definitions use the approved open-enrollment-first language.

## Unchanged

- Checkout and paid access remain disabled.
- No customer payment can occur.
- No routes, sitemap entries, public calculators, articles, or patient resources are removed.
- No Supabase, authentication, entitlement, Stripe, or analytics-payload changes are included.

## Validation status

Pending exact-head GitHub Actions, Vercel preview, browser certification, and production smoke verification.
