# How a Hospital Actually Makes Money — release amendment

Date: 2026-09-10
Applies to: `docs/work-packets/2026-09-10-how-a-hospital-actually-makes-money.md`

## Final monetization disposition

The original work packet proposed immediate light-ad eligibility for this new founder article. During exact-head release validation, CAF's runtime advertising governance correctly rejected the new route because the existing reconciled AdSense audit contains 42 affirmatively ad-eligible articles and CAF-D-025 is still running a bounded audience-validation cycle with no monetization expansion.

The release therefore adopts the more conservative final decision:

- publish `/articles/how-a-hospital-actually-makes-money` now;
- keep the article indexable and fully reviewed;
- keep it **ad-free-editorial** during the current audience-validation cycle;
- preserve the existing 42-route ad-eligible inventory unchanged;
- reconsider light advertising at the next publisher review, scheduled for 2026-10-10, using actual readership evidence rather than expanding monetization mid-experiment.

This amendment supersedes the original work packet wherever that packet describes the new article as immediately ad-eligible. It does not change the article's editorial classification as a CAF flagship article.

## Why this is the safer release

The founder's explicit instruction to publish is honored without silently broadening the separate monetization experiment. Existing ads on previously reviewed routes remain unchanged. The new article can accumulate Search Console and reader-behavior evidence without creating a moving advertising baseline.

The runtime review record, detailed publisher ledger, and article regression test have been aligned to this final disposition.
